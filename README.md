# Catálogo de Cursos com Componentes React

Projeto desenvolvido para a atividade de React, com foco em componentes reutilizáveis, props e organização de código.

## Objetivo

Criar uma página para apresentar cursos da área de tecnologia, utilizando componentes para evitar a repetição de código.

## Funcionalidades

- Cabeçalho com título e descrição.
- Cards com informações dos cursos.
- Componente de destaque reutilizável.
- Lista de cursos gerada com `map()`.
- Exibição de vagas disponíveis ou indicação de turma completa.
- Layout responsivo para computadores e celulares.
- Rodapé informativo.

## Componentes

- `Cabecalho.jsx`: apresenta o título e a descrição.
- `CardCurso.jsx`: exibe as informações de cada curso por meio de props.
- `Destaque.jsx`: apresenta mensagens de destaque.
- `Rodape.jsx`: apresenta as informações finais da página.

## Tecnologias utilizadas

- React
- JavaScript
- Vite
- CSS
- Git e GitHub

## Como executar o projeto

1. Instale o Node.js.
2. Clone este repositório.
3. Execute `npm install`.
4. Execute `npm run dev`.
5. Abra no navegador o endereço local indicado no terminal.
